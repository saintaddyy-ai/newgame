# ПЛАТИНА

2D-драма о рэпере с окраины, который пробивается наверх. Сюжет ветвится от выборов игрока, концовок три. 18+.

**Сейчас готово:** Пролог «Гараж» и Эпизод 1 «Сломанный микрофон».

## Управление
| Клавиша | Действие |
|---|---|
| ← → / A D | Ходить |
| E / Пробел | Осмотреть, поговорить, листать диалог |
| 1–6 | Выбрать ответ |
| Q | Тетрадь: цель, строчки, вещи в карманах |

На телефоне управление кнопками на экране. Прогресс сохраняется в браузере: в меню есть «Продолжить» и «Сразу Эпизод 1».

## Запуск у себя
```
npm install
npm run dev
```
Открой http://localhost:5173

## Озвучка
Реплики из `src/story/*.js` озвучиваются одной командой. Голоса персонажей настраиваются в `src/data/voices.json`.
```
npm run voice -- --dry                         # сколько реплик и символов, без генерации
ELEVENLABS_API_KEY=... npm run voice           # ElevenLabs (по умолчанию)
VOICE_PROVIDER=yandex YANDEX_API_KEY=... npm run voice   # Yandex SpeechKit
```
Файлы ложатся в `public/voice/`, генерируются только новые реплики. Без файлов игра идёт молча.

## Устройство
- `src/story/prologue.js`, `src/story/episode1.js`: локации, диалоги, выборы
- `src/story/shared.js`: общие локации (ванная)
- `src/story/backdrops.js`: фоны
- `src/art.js`: пиксельные спрайты и афиши
- `public/portraits/`: портреты персонажей для окна диалога
- `src/state.js`: флаги, характеристики, строчки, деньги, сохранения
- `src/scenes/`: экраны (локация, запись трека, склад, итоги)
- `src/ui/`: диалог, тетрадь, комп Дэна
- `scripts/voice.mjs`: генерация озвучки

При пуше в `main` игра автоматически выкладывается на GitHub Pages (`.github/workflows/deploy.yml`).
