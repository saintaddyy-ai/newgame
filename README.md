# ПЛАТИНА

2D-драма о рэпере с окраины, который пробивается наверх. Сюжет ветвится от выборов игрока, концовок три. 18+.

**Сейчас готово:** Пролог «Гараж», Эпизод 1 «Сломанный микрофон» и Эпизод 2 «Открытый микрофон» (пятница → воскресенье, город, «Подвал», девушки, курьер Рея, 13 независимых заданий — последнее: джингл для «Шаурмы 24»).

## Управление
| Клавиша | Действие |
|---|---|
| ← → / A D | Ходить |
| E / Пробел | Осмотреть, поговорить, листать диалог |
| 1–6 | Выбрать ответ |
| Shift + ← → | Идти тихо (проскользнуть мимо мамы и не только) |
| Q | Тетрадь: цель, строчки, вещи в карманах (марочку «на потом» можно использовать оттуда) |
| P | Телефон: дела, сообщения, звонки, камера, галерея, плеер, диктофон, банк, соцсети, карта, настройки |
| [ ] | Сдвинуть телефон влево / вправо (или тянуть его за рамку мышью/пальцем; положение запоминается) |

На телефоне управление кнопками на экране, колёсиком мыши (прокрутка) и стрелками. Прогресс сохраняется в браузере:
в меню есть «Продолжить», «Сразу Эпизод 1» и «Сразу Эпизод 2». Долго идёшь в одну сторону — Марк разгоняется.

## Телефон
- **Положение:** слева / в центре / справа — клавишами `[` `]`, перетаскиванием за рамку или в «Настройках».
- **Настройки:** громкость музыки, звуков и голосов, озвучка, скорость текста, автотюн, наушники, положение телефона,
  **качество графики** (высокая / средняя / низкая), **яркость** (90–130 %), обои.
- Уведомления встают в очередь и не перекрывают диалог и кнопки; звонки, пришедшие во время сцены, дозваниваются потом.

## Сытость и чистота (Эпизоды 1 и 2)
Три полоски под деньгами: ⚡ силы (Эп.2), сытость, чистота. То же — в тетради и в «Делах» телефона («Самочувствие»).
- **Сытость** падает со временем (Эп.2 — по часам, Эп.1 — между фазами дня). Голод → предупреждения → слабость
  (медленнее ходишь, быстрее устаёшь) → «последнее предупреждение» → обморок и экран «Конец»
  с «Загрузить последнее сохранение». Поесть: холодильник и мама дома, шаурма, кафе, «Продукты» за аркой.
- **Чистота** падает со временем и от «грязных» дел (склад, концерт, погоня, драка, ночь вне дома, дождь).
  Мама, девушки, Дэн, Стас и охрана «Подвала» реагируют; фото и стримы с Марком собирают меньше подписчиков.
  Помыться: ванна дома, раковина в каморке у Дэна.
- Когда пора — в «Делах» появляются «Поесть» и «Помыться» с подсказкой, куда идти. Старые сохранения загружаются.

## Студия
Запись в будке: в наушниках микрофон пишется «как есть» (без эхо- и шумоподавления браузера), потом сводится:
гейт, эквалайзер, де-эссер, компрессор, дабл, дилей на 1/8 и реверб. Автотюн (клавиша A): выкл / лёгкий / жёсткий,
в тональности бита (ми минор). Есть тест микрофона и сравнение «до / после». Демки сохраняются в WAV.
Если голоса не слышно (микрофон не дался или молчал), игра не сохраняет молча: предложит проверить микрофон
и перезаписать — или явно сохранить «инструментал».

## Запуск у себя
```
npm install
npm run dev
```
Открой http://localhost:5173

## Озвучка
Реплики из `src/story/*.js` озвучиваются одной командой. Голоса персонажей настраиваются в `src/data/voices.json`.
```
npm run voice -- --dry                         # сколько реплик и символов, без генерации
npm run voice -- --dry --list=docs/voice-todo.md   # список неозвученных реплик по персонажам
ELEVENLABS_API_KEY=... npm run voice           # ElevenLabs (по умолчанию)
VOICE_PROVIDER=yandex YANDEX_API_KEY=... npm run voice   # Yandex SpeechKit
```
Файлы ложатся в `public/voice/`, генерируются только новые реплики. Без файлов игра идёт молча.

## Графика
Вся графика рисуется кодом — сторонних картинок нет (`docs/LICENSES.md`). Арт 480×270, на экране ×2, **1 м = 36 px**
(Марк 1,75 м ≈ 63 px). Палитра, рампы и свет — `docs/palette.md`.
- `src/gfx/pix.js` — холст-«пиксельная бумага» (прямоугольники, линии, эллипсы, контур, дизеринг);
  `color.js` — рампы цветов; `font.js` — пиксельный шрифт вывесок.
- `src/gfx/chars.js`, `cast.js`, `actors.js` — персонажи 3/4 (два глаза), анимации (ходьба, разговор, еда, телефон…);
  `portraits.js` — портреты с эмоциями для диалогов.
- `src/gfx/world.js`, `time.js` — слои с параллаксом, небо по времени суток, ночь и свет фонарей/окон;
  `paint.js`, `interior.js`, `doors.js` — фасады, комнаты в разрезе, двери с тем, что за ними;
  `src/gfx/places/*` — рисовальщики всех локаций.
- `src/gfx/life.js` — голуби, кот, вороны, листья, пар, прохожие вдали; `weather.js` — дождь, снег, туман, пыль;
  `fx.js` — плёночный эффект, аберрация, «кислота»; `quality.js` — уровни качества; `actions.js` — анимации действий
  (зеркало с отражением, холодильник, сон, душ, метро, живые NPC).
- `src/ui/frame.js` — пиксельные рамки интерфейса (работают и в WebGL, и в Canvas).

## Тесты
- `node tests/clicks.cjs` — реальные клики мышью и пальцем по спискам (тетрадь «Отдать Рею», варианты ответа,
  комп Дэна, телефон) при пяти размерах окна и сдвинутом холсте. Нужен запущенный `npx vite preview --port 4173`
  и Playwright (`npm i -D playwright && npx playwright install chromium`).
- `node scripts/screens.cjs docs/screens/after 4173` — скриншоты ключевых экранов (до/после — в `docs/screens/`).

## Устройство
- `src/story/prologue.js`, `src/story/episode1.js`: локации, диалоги, выборы
- `src/story/episode2/`: Эпизод 2 — время и настроение (`world.js`), люди (`people.js`, `workers.js`), фоны (`scenery.js`),
  сюжет (`main.js`, `podval.js`, `girls.js`), город (`city.js`), задания (`side.js`, джингл — `jingle.js`), курьер Рея (`courier.js`), метро (`metro.js`), локации (`locations.js`)
- `src/needs.js`, `src/story/remarks.js`: сытость и чистота, реакции людей; `src/scenes/OverScene.js` — экран «Конец»
- `src/story/phoneStory.js`, `src/phone/model.js`, `src/ui/Phone.js`: телефон
- `src/studio/fx.js`: студийная обработка голоса и автотюн
- `src/story/shared.js`: общие локации (ванная)
- `src/story/backdrops.js`: фоны
- `src/art.js`: спрайт-листы персонажей, афиши, текстуры эффектов
- `public/portraits/`: старые фотопортреты (игра их больше не использует, оставлены как были)
- `src/state.js`: флаги, характеристики, строчки, деньги, сохранения
- `src/scenes/`: экраны (локация, запись трека, концерт, погоня, склад, итоги)
- `src/ui/`: диалог, тетрадь, комп Дэна, телефон, рамки интерфейса
- `scripts/voice.mjs`: генерация озвучки

При пуше в `main` игра автоматически выкладывается на GitHub Pages (`.github/workflows/deploy.yml`).
