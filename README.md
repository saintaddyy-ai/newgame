# ПЛАТИНА

2D-драма о рэпере с окраины, который пробивается наверх. Сюжет ветвится от выборов игрока, концовок три. 18+.

**Сейчас готово:** демо, Пролог «Гараж».

## Управление
| Клавиша | Действие |
|---|---|
| ← → / A D | Ходить |
| E / Пробел | Осмотреть, поговорить, листать диалог |
| 1–3 | Выбрать ответ |
| Q | Тетрадь со строчками |

На телефоне управление кнопками на экране.

## Запуск у себя
```
npm install
npm run dev
```
Открой http://localhost:5173

## Устройство
- `src/story/prologue.js`: локации, диалоги и выборы пролога
- `src/story/backdrops.js`: фоны
- `src/art.js`: пиксельные спрайты-заглушки
- `src/state.js`: флаги, характеристики, собранные строчки
- `src/scenes/`: экраны игры (локация, запись трека, итоги)
- `src/ui/`: окно диалога и тетрадь

При пуше в `main` игра автоматически выкладывается на GitHub Pages (`.github/workflows/deploy.yml`).
