# ПЛАТИНА

2D-драма о рэпере с окраины, который пробивается наверх. Сюжет ветвится от выборов игрока, концовок три. 18+.

**Сейчас готово:** Пролог «Гараж», Эпизод 1 «Сломанный микрофон» и Эпизод 2 «Открытый микрофон» (пятница → воскресенье, город, «Подвал», девушки, курьер Рея, 13 независимых заданий — последнее: джингл для «Шаурмы 24»).

## Управление
| Клавиша | Действие |
|---|---|
| ← → / A D | Ходить |
| E / Пробел | Осмотреть, поговорить, листать диалог |
| 1–6 | Выбрать ответ |
| Shift + ← → | Идти тихо (проскользнуть мимо мамы и не только) |
| Q | Тетрадь: цель, строчки, вещи в карманах (марочку «на потом» можно использовать оттуда) |
| P | Телефон: дела, сообщения, звонки, камера, галерея, плеер, диктофон, банк, соцсети, карта, настройки |

На телефоне управление кнопками на экране. Прогресс сохраняется в браузере: в меню есть «Продолжить», «Сразу Эпизод 1» и «Сразу Эпизод 2».

## Студия
Запись в будке: в наушниках микрофон пишется «как есть» (без эхо- и шумоподавления браузера), потом сводится:
гейт, эквалайзер, де-эссер, компрессор, дабл, дилей на 1/8 и реверб. Автотюн (клавиша A): выкл / лёгкий / жёсткий,
в тональности бита (ми минор). Есть тест микрофона и сравнение «до / после». Демки сохраняются в WAV.

## Запуск у себя
```
npm install
npm run dev
```
Открой http://localhost:5173

## Озвучка
Реплики из `src/story/*.js` озвучиваются одной командой. Голоса персонажей настраиваются в `src/data/voices.json`.
```
npm run voice -- --dry                         # сколько реплик и символов, без генерации
ELEVENLABS_API_KEY=... npm run voice           # ElevenLabs (по умолчанию)
VOICE_PROVIDER=yandex YANDEX_API_KEY=... npm run voice   # Yandex SpeechKit
```
Файлы ложатся в `public/voice/`, генерируются только новые реплики. Без файлов игра идёт молча.

## Устройство
- `src/story/prologue.js`, `src/story/episode1.js`: локации, диалоги, выборы
- `src/story/episode2/`: Эпизод 2 — время и настроение (`world.js`), люди (`people.js`, `workers.js`), фоны (`scenery.js`),
  сюжет (`main.js`, `podval.js`, `girls.js`), город (`city.js`), задания (`side.js`), курьер Рея (`courier.js`), метро (`metro.js`), локации (`locations.js`)
- `src/story/phoneStory.js`, `src/phone/model.js`, `src/ui/Phone.js`: телефон
- `src/studio/fx.js`: студийная обработка голоса и автотюн
- `src/story/shared.js`: общие локации (ванная)
- `src/story/backdrops.js`: фоны
- `src/art.js`: пиксельные спрайты и афиши
- `public/portraits/`: портреты персонажей для окна диалога
- `src/state.js`: флаги, характеристики, строчки, деньги, сохранения
- `src/scenes/`: экраны (локация, запись трека, концерт, погоня, склад, итоги)
- `src/ui/`: диалог, тетрадь, комп Дэна
- `scripts/voice.mjs`: генерация озвучки

При пуше в `main` игра автоматически выкладывается на GitHub Pages (`.github/workflows/deploy.yml`).
