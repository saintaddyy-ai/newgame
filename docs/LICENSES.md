# Лицензии и происхождение ресурсов

## Графика

Вся графика игры (персонажи, портреты, фоны, двери, машины, животные, интерфейс, эффекты)
**рисуется процедурно кодом проекта** в `src/gfx/*`, `src/art.js`, `src/ui/*` — сторонних
картинок и спрайт-листов в игре нет.

Файлы `public/portraits/*.png` — фотопортреты, которые прислал автор проекта (ранние версии
игры показывали их в диалогах). С переходом на единый пиксельный стиль игра их не использует,
файлы оставлены в репозитории без изменений.

| Шрифт | Автор | Лицензия | Откуда |
|---|---|---|---|
| Press Start 2P | CodeMan38 | SIL Open Font License 1.1 | npm `@fontsource/press-start-2p` |
| PT Mono | ParaType | SIL Open Font License 1.1 | npm `@fontsource/pt-mono` |

Маленький пиксельный шрифт для вывесок (`src/gfx/font.js`, 5 px) нарисован для проекта.

## Звук

* Все звуковые эффекты и фоновые «эмбиенты» синтезируются в коде (`src/audio.js`, Web Audio).
* `public/audio/beat-yagoda.mp3` — бит Дэна, добавлен автором проекта.
* `public/voice/*.mp3` — озвучка реплик, сгенерирована автором через ElevenLabs своим ключом
  (`scripts/voice.mjs`); права — по условиям ElevenLabs для владельца ключа.
