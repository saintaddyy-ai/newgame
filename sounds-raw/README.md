# Исходные звуки для игры

Сюда загружаются записанные звуки (любой формат: m4a, mp3, wav).
Claude обрежет их, выровняет громкость, сожмёт и подключит в игру (`public/sfx/`).

Загрузка: на GitHub зайди в эту папку → **Add file → Upload files** → перетащи файлы → **Commit changes**.

Названия файлов — по списку: `dver_otkryt`, `dver_zakryt`, `dver_vhod`, `shagi_pol`, `shagi_asfalt`,
`dozhd`, `holodilnik`, `meloch` и остальные. Если не знаешь, как назвать, — называй как хочешь, разберёмся.
